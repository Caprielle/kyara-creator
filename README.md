# kyara-creator：授業用キャラクター設定作成スキル（Gemini向け）

教科書を使った授業で、学習者の対話相手となる人物（キャラクター）の設定をすばやく作成・編集するためのスキルです。授業のねらいに合わせて人物の立場や考え方を整理し、GeminiのGemで使える対話用プロンプトを生成します。

## 開発の背景

「インターフェース論」の受講学生による企画グループの一員として、以下のワークショップの準備に取り組んでいます。本スキルは、その準備に用いる人物設定の作成支援ツールとして開発しています。

| 項目 | 内容 |
|---|---|
| 研究会 | 学習科学青山研究所2027年度研究会：生成AIと教育の現在地（仮） |
| プログラム | 第３部：生成AIと教科書活用 |
| 対象ワークショップ | 生成AI×教科書で学ぶワークショップ |
| 企画 | 「インターフェース論」受講学生 |

## 目的

教科書の内容や学習目標に沿った人物設定を短時間で作成し、授業準備の負担を減らすことを目指します。

作成する人物には、それぞれの立場、経験、大切にしていることなどを設定します。学習者がAIの演じる人物と対話し、異なる立場から教科書の内容を考え、自分の考えを見直す活動に活用します。

## スキルでできること

| 操作 | 内容 |
|---|---|
| 新規作成 | 教材や授業のねらいをもとに、人物設定の基本案を作成します。 |
| 追加・編集 | 既存の設定に人物を追加したり、立場や話し方などを変更したりします。 |
| 出力 | 保存・編集用の「設定資料」と、Gemの指示欄に貼り付ける「Gem用プロンプト」を生成します。 |

提供された資料の事実と、対話のために創作した人物設定を区別します。教科書の内容が必要な場合は該当箇所を提供し、不明な内容を事実として補わないようにします。

人物設定は、以下の「役割カード」の形式で整理します。複数の役割を一つの設定にまとめることもできます。

## ファイルと出力

| 名前 | 用途 |
|---|---|
| [`kyara-creator.md`](kyara-creator.md) | Geminiに読み込ませる、人物設定の作成・編集用スキルです。 |
| [`README.md`](README.md) | 開発の背景と使い方をまとめた説明書です。スキルへの読み込みは不要です。 |
| 設定資料 | スキルが生成する、保存・編集用の人物設定です。 |
| Gem用プロンプト | スキルが生成する、人物として対話するための指示です。 |

## Geminiへの設定

1. アップロード用に `kyara-creator.md` のコピーを作り、ファイル名を `SKILL.md` にします。
2. Geminiウェブ版の「カスタマイズ」→「スキル」を開きます。
3. アップロードから `SKILL.md` を選び、内容を確認して「作成」を押します。
4. チャットで `/`（画面によっては `@`）を入力し、`kyara-creator` を選びます。

スキルの利用には、18歳以上のログイン済みアカウントと「アクティビティの保存」が必要です。有料のGoogle AIサブスクリプションは不要です。手順・利用条件は[Google公式ヘルプ](https://support.google.com/gemini/answer/17094296?co=GENIE.Platform%3DDesktop&hl=ja)を参照してください。

## 基本の使い方

1. **話題・役割・授業のねらいを伝える。** 手書きの設定文、既存のプロンプト、教材も利用できます。
2. **短い基本案を確認する。** 提供された事実・条件、暫定の創作設定、未確定事項が分けて示されます。不明点への質問には一つずつ答えます。
3. **完成版を依頼する。** 「設定資料とGem用プロンプトを出力してください」と伝えます。二つは別々のコードブロックで出力されます。
4. **保存して使う。** 「設定資料」を手元に保存し、「Gem用プロンプト」の本文全体をGemの指示欄に貼り付けて保存します。詳しい操作は[Gemの公式ヘルプ](https://support.google.com/gemini/answer/15146780?hl=ja)を参照してください。

### 依頼の例

```text
話題は「スーパーのもやしの価格」です。
授業の仮定として、近所のスーパーがもやしを1円で売ろうとしています。
対話相手は「市場のはたらきと経済」を学んでいる中学生です。
役割は、もやし生産者、家計の支出を抑えたい消費者、近所の八百屋さんです。
学習目標は、安い価格がそれぞれの立場に与える影響を比べ、理由を説明できることです。
まず簡単な基本案を示してください。不明な事実は確認してください。
```

この例の「1円」は授業用の仮定です。商品の量や販売期間、仕入れ価格などは指定していないため、確認が必要な項目として扱います。

## 役割カードの構成

共通の授業設定は一度だけまとめ、役割ごとの事情を各カードに記します。

| 区分 | 項目 |
|---|---|
| 共通の授業設定：3項目 | 対話相手・学習範囲／話題・共通状況／学習目標 |
| 役割カード：6項目 | 役割・他者との関係／目的・優先順位／具体的な経験・行動／事実・認識・不明点／気づいてほしいこと・手がかり／対話の進め方 |

管理用に、設定名・版番号・役割ID（`R01`など）・各役割の所属話題を付けます。役割本人の望みと、学習者に身につけてほしいことは分けて設定します。

## 完成したGemでの対話

最初は全員が回答するモードです。各役割は通常2〜3文で答え、役割名のラベルを付けます。

| 入力例 | 動作 |
|---|---|
| `もやし生産者として答えて` | 指定した役割に切り替え、次の切り替えまで維持します。 |
| `R01として答えて` | 役割IDで切り替えます。 |
| `全員の意見を聞きたい` | 全員がそれぞれ答えるモードに戻ります。 |
| `立場の違いを整理して` | 一時的に各立場の関心と意見の違いを整理します。 |
| `今の役割を教えて` | 現在の回答モードを確認します。 |

一つのAIが複数の役割を演じます。それぞれが独立したAIや記憶を持つ仕組みではありません。

## 設定を変更するとき

作成用スキルに、最新の「設定資料」と変更内容を渡します。新しい会話では、保存した設定資料を添えてください。

```text
添付した設定資料のR01について、「目的・優先順位」を変更してください。
安定した取引の継続を最優先にしてください。
関係のない設定は維持し、設定資料とGem用プロンプトの完成版を出力してください。
```

更新された設定資料を保存し、新しいプロンプト全体でGemの指示を置き換えて保存します。役割の追加や話題の変更も依頼できます。役割カードを編集しても、保存済みのGemに自動で反映されるわけではありません。

## 生成・対話のルール

- 事実は提供された資料や確認できる根拠に基づきます。原価・利益・法律上の判断・教科書の引用などを創作で埋めません。
- 性格・口調・架空の生活背景などは適度に補い、「創作した役割設定（暫定）」と区別します。不確かな内容は一つずつ質問します。
- 教材が未提供なら、教材を読んだ前提で説明しません。もやしの店頭販売価格と、生産者の出荷価格も区別します。
- 役割は当事者として事情や手がかりを少しずつ伝えます。唯一の正解や全員の合意を先に決めず、学習者が判断する余地を残します。
- 作成・編集・役割との対話は日本語で行います。API・プラグイン・追加スクリプトは使いません。

Geminiアカウントへの設定と、実際の対話動作の確認は未実施です。
